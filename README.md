## 🌟 معرفی پروژه

پلتفرم **فروشگاه و کارگاه شیاسی** یک سامانه تجارت الکترونیک مدرن، سریع، فول‌استک و راست‌به‌چپ (RTL) با پشتیبانی کامل از هر دو حالت **تم روز (Light Mode)** و **تم شب (Dark Mode)** است که به‌صورت اختصاصی برای صنف لوازم برقی، تهویه، سیم و کابل استاندارد و کارگاه عیب‌یابی در **شهرستان نجف‌آباد و استان اصفهان** توسعه داده شده است.

## ✨ ویژگی‌های کلیدی پلتفرم

### 🛒 ۱. تجربه خرید هوشمند و کاتالوگ محصولات
* **پشتیبانی کامل از دو تم Light & Dark:** هماهنگی ۱۰۰٪ پالت رنگی (`Slate / Amber / Electric Blue / Rose / Emerald`) با استانداردهای کنتراست WCAG.
* **تخفیف‌های پلکانی خودکار در سبد خرید:** ۵٪ تخفیف برای سفارش‌های بالای ۱۰ عدد و ۱۰٪ تخفیف برای سفارش‌های بالای ۵۰ عدد.
* **پیشنهادات شگفت‌انگیز (Amazing Offers):** اسلایدر افقی لمسی با درصد تخفیف واقعی، قیمت خط‌خورده و افزودن سریع به سبد.
* **جستجوی زنده چندکلمه‌ای (Live Search):** جستجوی آنی در عنوان، برند، دسته‌بندی و کد فنی با امکان فیلتر بر اساس برند و محدوده قیمت.
* **هدر چسبنده شناور (Sticky Floating Header):** نوار بالایی هوشمند که هنگام اسکرول به پایین نرم و فشرده می‌شود و دسترسی به منو، سبد خرید، حساب کاربری و تغییر تم را در هر نقطه حفظ می‌کند.

### 🛠️ ۲. سامانه پذیرش و تعمیرات آنلاین (`/repair-service`)
* پذیرش آنلاین و حضوری انواع دستگاه‌ها:
  * 🌀 **پنکه** (ایستاده، رومیزی، سقفی، تعویض بوش، خازن و ریموت)
  * ❄️ **موتور و پمپ کولر آبی** (موتوژن، الکتروژن، تعویض پلاتین و سیم‌پیچی)
  * 🔥 **بخاری برقی و هیتر تابشی** (المنت‌های کوارتز اخوان، فن توربو و ترموستات)
  * 📡 **آنتن تلویزیون و بوستر دیجیتال** (هانی، تقویت‌کننده و منبع تغذیه)
  * 🔌 **سایر لوازم برقی خانگی و کارگاهی** (چای‌ساز، جاروبرقی، اتو، محافظ برق، سشوار و دریل)
* **صدور کد پذیرش یکتا (`REP-YYMMDD-XXXX`):** پیگیری وضعیت، گزارش کارشناسی و هزینه تعمیرات با شماره تماس یا کد پذیرش.

### 🧮 ۳. محاسبه‌گر مهندسی سایز کابل و افت ولتاژ
* محاسبه دقیق جریان مصرفی بر اساس بار مصرفی (وات/کیلووات)، مسافت سیم‌کشی و نوع برق (۲۲۰ ولت تک‌فاز / ۳۸۰ ولت سه‌فاز).
* تعیین سایز استاندارد سیم مسی آنیل شده و تیپ کلید مینیاتوری (B10, B16, C25, C32, C50).
* کنترل افت ولتاژ استاندارد زیر ۳٪ مطابق مبحث ۱۳ مقررات ملی ساختمان ایران.
* امکان افزودن ۱-کلیکه پکیج کابل متراژ دلخواه + فیوز مینیاتوری به سبد خرید.

### 📋 ۴. ابزار خرید گروهی و استعلام لیست قطعات (`/bom-upload`)
* امکان الصاق متن یا بارگذاری فایل اکسل/PDF لیست قطعات پروژه‌های ساختمانی.
* تطبیق هوشمند اقلام با انبار فروشگاه جهت صدور پیش‌فاکتور همکار با تخفیف عمده.

### 📄 ۵. پیش‌فاکتور رسمی حقوقی و مالیاتی
* امکان سفارش به‌صورت **شخص حقیقی** یا **شخص حقوقی / شرکتی**.
* ثبت نام شرکت، کد اقتصادی و شناسه ملی در پیش‌فاکتور رسمی با قابلیت چاپ مستقیم A4 (`window.print()`).

### 📱 ۶. احراز هویت پیامکی ایرانی (NextAuth + OTP)
* ورود سریع با کد تایید ۵ رقمی پیامک (OTP) یا شماره همراه.
* پنل اختصاصی مشتریان (`/account`) برای مشاهده سوابق خرید، چاپ فاکتورها و وضعیت تیکت‌های تعمیراتی.

## 🚀 راهنمای نصب و اجرا

### پیش‌نیازها
* **Node.js**: نسخه `18.18.0` یا بالاتر (تست‌شده روی Node 20 و 22)
* **PostgreSQL**: نسخه `14` یا بالاتر
* **Git**

### ۱. کلون و نصب پکیج‌ها
```bash
git clone https://github.com/your-username/electricity-shop-isfahan.git
cd electricity-shop-isfahan
npm install
```

### ۲. تنظیم متغیرهای محیطی (`.env`)
فایل `.env.example` را به `.env` کپی کرده و اطلاعات اتصال دیتابیس را وارد کنید:
```env
DATABASE_URL="postgresql://postgres:password@localhost:5432/electricity_shop?schema=public"
NEXTAUTH_SECRET="your-super-secret-key-at-least-32-chars"
NEXTAUTH_URL="http://localhost:3000"
```

### ۳. آماده‌سازی دیتابیس و داده‌های اولیه
```bash
npm run db:setup
```

### ۴. اجرای برنامه در محیط توسعه
```bash
npm run dev
```
سامانه در آدرس `http://localhost:3000` آماده به کار خواهد بود.
