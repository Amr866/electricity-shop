## 🌟 معرفی پروژه

پلتفرم **فروشگاه تخصصی شیاسی** یک فروشگاه اینترنتی مدرن، سریع و فول‌استک راست‌به‌چپ (RTL) است که به‌صورت اختصاصی برای بازار لوازم برقی، تهویه سرمایشی/گرمایشی، روشنایی و کارگاه خدمات فنی در **شهرستان نجف‌آباد و استان اصفهان** توسعه داده شده است.

این سیستم با الهام از برترین نمونه‌های موفق بازار ایران (مانند *ادیسون‌کالا*، *الکسترا* و *روبوای‌کیو*) طراحی شده و تلفیقی از خرید خرده‌فروشی، سفارش عمده پروژه‌ای و رهگیری آنلاین تعمیرات را ارائه می‌دهد.

## ✨ ویژگی‌های کلیدی پلتفرم

### 🛒 ۱. تجربه خرید هوشمند (E-Commerce)
* **تخفیف‌های پلکانی خودکار در سبد خرید:** محاسبه خودکار ۵٪ تخفیف برای سفارش‌های بالای ۱۰ عدد و ۱۰٪ تخفیف برای سفارش‌های بالای ۵۰ عدد.
* **پیشنهادات شگفت‌انگیز (Amazing Offers):** بنر چرخشی با تایمر معکوس و درصد تخفیف واقعی کالاها.
* **جستجوی زنده آنی (Live Search):** جستجوی در لحظه بین عنوان کالا، دسته‌بندی و کد SKU به همراه پیش‌نمایش تصویر و قیمت.
* **فیلترهای پیشرفته:** فیلترینگ کالاها بر اساس محدوده قیمت، موجودی انبار، برندهای سازنده و ارسال سریع.

### 🛠️ ۲. سامانه پذیرش و تعمیرات آنلاین (`/repair-service`)
* پذیرش آنلاین انواع دستگاه‌ها:
  * 🌀 **پنکه** (ایستاده، رومیزی، سقفی، تعویض بوش، خازن و ریموت)
  * ❄️ **موتور و پمپ کولر آبی** (موتوژن، الکتروژن، تعویض پلاتین و سیم‌پیچی)
  * 🔥 **بخاری برقی و هیتر تابشی** (المنت‌های کوارتز اخوان، فن توربو و ترموستات)
  * 📡 **آنتن تلویزیون و بوستر دیجیتال** (هانی، تقویت‌کننده و منبع تغذیه)
  * 🔌 **سایر لوازم برقی و متفرقه (غیره)** (چای‌ساز، جاروبرقی، اتو، محافظ برق، سشوار و ابزارآلات برقی)
* **صدور کد پذیرش یکتا (`REP-YYMMDD-XXXX`):** استعلام لحظه‌ای وضعیت تعمیر، یادداشت کارشناس و برآورد هزینه با شماره همراه یا کد پذیرش.

### 📋 ۳. ابزار خرید گروهی قطعات و BOM Upload (`/bom-upload`)
* امکان الصاق متن یا بارگذاری فایل اکسل و لیست قطعات پروژه‌های برق و الکترونیک.
* تطبیق هوشمند لیست مهندسی با موجودی انبار فروشگاه و افزودن یک‌کلیکه تمامی اقلام به سبد خرید.

### 📄 ۴. فاکتور رسمی حقوقی و مالیاتی
* امکان انتخاب سفارش به‌صورت **شخص حقیقی** یا **شخص حقوقی / شرکتی**.
* ثبت خودکار نام شرکت، کد اقتصادی و شناسه ملی در پیش‌فاکتور رسمی استاندارد با قابلیت چاپ مستقیم (`window.print()`).

### 📱 ۵. احراز هویت پیامکی ایرانی (NextAuth + OTP)
* ورود بدون رمز با کد تایید ۵ رقمی پیامک (OTP).
* پنل اختصاصی مشتریان (`/account`) شامل آرشیو سفارش‌ها، فاکتورهای چاپ‌پذیر و تیکت‌های تعمیراتی فعال.

### 🗺️ ۶. بومی‌سازی کامل و موقعیت نجف‌آباد
* آدرس دقیق، شماره‌های تماس کارگاه و فروشگاه، و اتصال مستقیم به **Google Maps**.
* محاسبه گزینه‌های ارسال با پیک اختصاصی نجف‌آباد، اسنپ‌باکس استانی و تیپاکس سراسری.

```
│   ├── app/
│   │   ├── account/        # پنل کاربری مشتری و تاریخچه فاکتورها

│   │   ├── api/            # اندپوینت‌های ایمن API (تسویه‌حساب، تعمیرات، احراز هویت، تخفیف)
│   │   ├── auth/           # فرم ورود پیامکی و ورود مدیریت
│   │   ├── bom-upload/     # بارگذاری و تطبیق لیست قطعات مهندسی
│   │   ├── cart/           # سبد خرید با محاسبه خودکار تخفیف پلکانی

│   │   ├── products/       # کاتالوگ جامع، فیلترها و صفحه اختصاصی محصول با JSON-LD
│   │   ├── repair-service/ # فرم پذیرش آنلاین و استعلام وضعیت تعمیرات
│   │   └── zarinpal-mock/  # شبیه‌ساز پرداخت درگاه زرین‌پال
│   ├── components/
│   │   ├── brand/          # سوئیچ زنده هویت‌های برند
│   │   ├── home/           # بخش‌های صفحه اصلی (HeroBanner، پیشنهادات، کارگاه فنی)
│   │   ├── layout/         # هدر، فوتر ریسپانسیو و ناوبری موبایل
│   │   └── product/        # کارت محصول، گالری تصاویر و نظرات
│   ├── context/            # کانتکست‌های ری‌اکت (CartContext, BrandContext, WishlistContext)
│   └── lib/                # پیکربندی Auth، کلاینت Prisma و توابع کاربردی تاریخ شمسی
```

## 🚀 راهنمای نصب و اجرا

### پیش‌نیازها
* **Node.js**: نسخه 18.18 یا بالاتر
* **PostgreSQL**: فعال روی پورت `5432`

### ۱. کلون پروژه و نصب پکیج‌ها
```bash
git clone https://github.com/your-username/electricity-shop.git
cd electricity-shop
npm install
```

### ۲. تنظیم متغیرهای محیطی (`.env`)
فایل `.env` را در ریشه پروژه ایجاد کرده و متغیرهای زیر را تنظیم کنید:
```env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/naghshejahan_db?schema=public"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="shiasi-secret-key-1403-najafabad-isfahan-auth"
```

### ۳. سینک دیتابیس و اجرای سید اولیه
```bash
npx prisma db push
node prisma/seed.js
```

### ۴. اجرای سرور توسعه
```bash
npm run dev
```
برنامه در آدرس [http://localhost:3000](http://localhost:3000) در دسترس خواهد بود.
